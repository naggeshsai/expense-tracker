## Getting Started

### First Launch
When you first launch the Expense Tracker app:
1. The app automatically creates 10 default categories
2. You'll see an empty dashboard
3. Tap the **+** (floating action button) to add your first expense

### Navigation
The app uses bottom navigation with four main sections:
- **Dashboard**: View spending analytics and charts
- **Expenses**: List and manage all expenses
- **Budget**: Set and track budgets
- **Settings**: Configure app preferences

## Dashboard

### Overview
The Dashboard provides a comprehensive view of your financial activity.

### Features

#### 1. Date Range Selector
- Tap the date range card at the top
- Select custom start and end dates
- Dashboard updates automatically with filtered data

#### 2. Total Spending Card
- Shows total spending for selected period
- Quick glance at your expenditure

#### 3. Category Breakdown
- **Pie Chart**: Visual representation of spending by category
- Percentages show proportion of each category
- Colors match category icons for easy identification

#### 4. Category List
- Detailed list below the chart
- Shows exact amount spent per category
- Sorted from highest to lowest spending

### Using the Dashboard

**View Current Month Spending:**
1. Open Dashboard (default view)
2. Date range is automatically set to current month

**View Custom Period:**
1. Tap the date range selector
2. Choose start date
3. Choose end date
4. View updated analytics

**Quick Stats:**
- Total spending displayed prominently
- Category breakdown helps identify spending patterns
- Use insights to adjust spending habits

## Managing Expenses

### Adding an Expense

1. **Tap the + Button** (available on any screen)
2. **Fill in Details:**
   - **Amount**: Enter expense amount (required)
   - **Category**: Select from dropdown (required)
   - **Payment Method**: Choose how you paid (Cash, Credit Card, etc.)
   - **Date**: Select transaction date (defaults to today)
   - **Note**: Add optional description
   - **Recurring**: Check if this is a recurring expense

3. **Save**: Tap "Add Expense" button

### Viewing Expenses

1. Navigate to **Expenses** tab
2. Scroll through list of all expenses
3. Each card shows:
   - Category icon and name
   - Amount
   - Date
   - Note (if added)

### Editing an Expense

1. Tap on any expense card
2. Modify any field
3. Tap "Update Expense"

### Deleting an Expense

1. Tap the delete icon on expense card
2. Confirm deletion in dialog
3. Expense is permanently removed

### Filtering Expenses

Use the filter icon in the top bar to:
- Filter by date range
- Filter by category
- Filter by payment method

### Empty State
If no expenses exist:
- Friendly message displayed
- Instructions to add first expense
- Tap + to get started

## Budget Tracking

### Why Set Budgets?
Budgets help you:
- Control spending
- Achieve financial goals
- Identify overspending areas
- Plan for future expenses

### Setting a Budget

1. Navigate to **Budget** tab
2. Tap the **+** button
3. Choose:
   - **Overall Budget**: Applies to all spending
   - **Category Budget**: Specific to one category
4. Enter:
   - Budget amount
   - Month and year
5. Save

### Monitoring Budgets

Each budget displays:
- **Category name**
- **Spent vs. Budget**: "\$150 / \$500"
- **Progress Bar**: Visual indicator
- **Percentage Used**: "30% used"
- **Warnings**: 
  - Orange at 80%
  - Red when over budget

### Budget Colors

- 🟢 **Green**: Under 80% (safe)
- 🟠 **Orange**: 80-100% (warning)
- 🔴 **Red**: Over 100% (over budget)

### Best Practices

- Set realistic budgets based on past spending
- Review and adjust monthly
- Use category budgets for problem areas
- Check progress weekly

3. 🎬 **Entertainment** - Movies, games, hobbies

8. ✈️ **Travel** - Flights, hotels, vacation
9. 🛒 **Groceries** - Supermarket purchases

### Viewing Categories

1. Navigate to **Categories** page (via settings or menu)
2. See all available categories
3. View icons and colors

### Creating Custom Categories

1. Tap **+** on Categories page
2. Enter:
   - Category name
   - Select icon
   - Choose color
3. Save

### Editing Categories

- Only custom categories can be edited
- Default categories are protected
- Tap category to edit name, icon, or color

### Deleting Categories

- Only custom categories can be deleted
- Tap delete icon
- Confirm deletion
- **Note**: Cannot delete if expenses exist in that category

## Tips & Best Practices

### Recording Expenses

✅ **Do:**
- Record expenses immediately
- Add descriptive notes
- Choose accurate categories
- Use recurring flag for regular expenses

❌ **Don't:**
- Delay recording (you might forget)
- Skip categories
- Mix personal and business expenses

### Budgeting

✅ **Do:**
- Start with overall budget
- Add category budgets for problem areas
- Review weekly
- Adjust based on actual spending
- Use warnings as early indicators

❌ **Don't:**
- Set unrealistic budgets
- Ignore warnings
- Give up after one bad month

### Categories

✅ **Do:**
- Use appropriate categories
- Keep category list manageable
- Use "Other" sparingly
- Review category spending monthly

❌ **Don't:**
- Create too many custom categories
- Mix different expense types
- Delete categories with historical data

### Analysis

✅ **Do:**
- Check dashboard weekly
- Compare month-over-month
- Identify spending trends
- Use date range selector
- Export data for detailed analysis

❌ **Don't:**
- Ignore the data
- Wait until month-end
- Overlook small expenses

### Data Backup

✅ **Do:**
- Export data monthly
- Keep backups safe
- Test restore process

❌ **Don't:**
- Rely only on device storage
- Delete backups prematurely

## Frequently Asked Questions

**Q: Can I track income?**
A: Currently, the app focuses on expenses. Income tracking may be added in future updates.

**Q: Is my data synced to cloud?**
A: Phase 1 is local-only. Cloud sync (Phase 2) is planned for future release.

**Q: Can I attach receipts?**
A: Not in current version. Planned for future updates.

**Q: How many expenses can I store?**
A: No limit. SQLite database can handle thousands of expenses efficiently.

**Q: Can I use on multiple devices?**
A: Currently, data is stored locally per device. Cloud sync coming in Phase 2.

**Q: What if I lose my phone?**
A: Regular exports (CSV) are recommended for backup. Cloud sync in Phase 2 will solve this.
